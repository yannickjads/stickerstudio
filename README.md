# Sticker Studio

An iOS app that turns photos and GIFs into sticker packs — square-cropped,
organised into packs, and sent straight to WhatsApp or Telegram.

Everything happens on the device. There is no account, no analytics, no server,
and the app never uses the network.

## What it does

- **Batch import** — pick a whole camera roll selection at once and crop them one
  after another, or centre them all in a single tap.
- **Animated GIFs stay animated** — every frame is cropped identically and
  re-encoded as a looping 512×512 GIF, on the phone.
- **30-slot packs** — the WhatsApp limit is shown as a fixed grid. Tap any empty
  slot to fill it; when a batch overflows, the next pack is created automatically.
- **Send to WhatsApp** — a real pack import, animated stickers included.
- **Send to Telegram** — via Telegram's own sticker-set import.
- **`.wastickers`** — export packs in the format other sticker apps read, and
  import theirs. Opening such a file from Files or AirDrop opens it here.
- **Backups** — export packs to a `.zip` and restore them later, slots and all.

## Building

The app is built by GitHub Actions on macOS runners; no Mac is needed locally.
Pushing to `main` produces a signed ad-hoc build and publishes it as a release
with an over-the-air install manifest.

Signing material (distribution certificate, provisioning profile) lives in
repository secrets and is never committed:

| Secret | Contents |
| --- | --- |
| `IOS_DIST_P12_BASE64` | base64 of the distribution `.p12` |
| `IOS_DIST_P12_PASSWORD` | password for that `.p12` |
| `IOS_ADHOC_PROFILE_BASE64` | base64 of the ad-hoc `.mobileprovision` |

Locally: `npm install`, then `npx tsc --noEmit` to typecheck. The native project
(`ios/`) is generated by `npx expo prebuild` and is deliberately not committed.

## Structure

| Path | |
| --- | --- |
| `src/screens/` | packs list, pack grid, crop flow |
| `src/db.ts` | SQLite repository — the only place file paths are translated |
| `src/storage.ts` | on-disk layout; paths are stored **relative** (iOS changes the container UUID on every install) |
| `src/editor/` | Skia rendering, GIF encoding, WebP muxing, WhatsApp/Telegram payloads |
| `modules/` | small Swift modules: WhatsApp import, Telegram import, native dialogs |
